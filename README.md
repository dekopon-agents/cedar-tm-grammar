# Cedar TextMate grammar

This repository packages the Cedar policy grammar from the [Cedar VS Code extension](https://github.com/cedar-policy/vscode-cedar/blob/eb63daec70f2ee8b14b049707cc787678918901b/syntaxes/cedar.tmLanguage.json) at commit `eb63daec70f2ee8b14b049707cc787678918901b` for use by GitHub Linguist. The grammar, license, and notice are unchanged. It excludes the separate Cedar Schema grammar, whose variable-length lookbehinds are rejected by Linguist's grammar compiler.
